================================================================================
 在庫分析 PowerPivot_ABC：初期テーブルの作成（0.1.x 用）
 作成：関根禎浩　2026-11-02
================================================================================

■ これは何か
  分析用ブックに手で作るテーブル6つを、Power Query で作るためのコード。

    No. クエリ名（＝テーブル名）  必須   中身
    A   設定                      必須   項目と初期値（フォルダパス2つ・開始日・終了日だけ空欄）
    B   経過措置リスト            任意   見出しだけ
    C   発注除外                  任意   見出しだけ
    D   在庫情報                  任意   見出しだけ
    E   追加休業日                任意   見出しだけ
    F   薬品グループ              任意   見出しだけ

  ※ 設定テーブルには、計算に使う値とフォルダだけを入れる。エリシアSの出力の列名・
    ファイル名はクエリ側に固定で書いてあるので、設定にはない
  ※ B～E は発注支援のブックに同じテーブルがあれば、中身をコピーして貼ってよい

■ 手順（PowerPivot_ABC の⓪～⑪より先に行う）
  1. 新しい空のブックを開く
  2. [データ]→[データの取得]→[その他のデータソースから]→[空のクエリ]
  3. [ホーム]→[詳細エディター]に A のコードを貼り付けて[完了]
  4. 右側「クエリの設定」の名前を、見出しのクエリ名（例：設定）に変える
  5. [ホーム]→[閉じて読み込む]（新しいシートにテーブルとして読み込まれる）
  6. B～F も同じように作る
  7. 読み込まれたテーブルを1つずつ選び、[テーブルデザイン]→[リンク解除] を押す
     （リンク解除しないと、[すべて更新]のたびに入力した内容が初期値に戻ってしまう）
  8. [データ]→[クエリと接続]で、A～F のクエリを右クリック→[削除]（テーブルは残る）
  9. 各テーブルの「テーブル名」が見出しのとおりか確認する（「設定_2」などになっていたら直す）
 10. 設定テーブルの「フォルダパス」「開始日」「終了日」「出納フォルダパス」を入力する
 11. このあと、dist/PowerPivot_ABC_<版>.txt の手順（プライバシー設定、⓪～⑪）に進む


// ================================================================================
// A クエリ名：設定
// ================================================================================
let
    Source = #table({"項目", "値"}, {
        {"フォルダパス",               null},
        {"開始日",                     null},
        {"終了日",                     null},
        {"出納フォルダパス",           null},
        {"標準の包装単位",             100},
        {"年末年始の休み始め",         "12/29"},
        {"年末年始の休み終わり",       "1/3"},
        {"発注日",                     null},
        {"不動とみなす月数",           3},
        {"在庫過多とみなす日数",       60},
        {"1箱消化の注意日数",          180},
        {"ずれの注意割合",             0.3},
        {"ずれの大きさの注意割合",     0.5}
    })
in
    Source


// ================================================================================
// B クエリ名：経過措置リスト
// ================================================================================
let
    Source = #table({"薬品名", "経過措置期限"}, {})
in
    Source


// ================================================================================
// C クエリ名：発注除外
// ================================================================================
let
    Source = #table({"薬品名", "理由", "登録日"}, {})
in
    Source


// ================================================================================
// D クエリ名：在庫情報
//    包装単位：1箱の数（100、500、1000 など）。列数：棚の区画の列数
// ================================================================================
let
    Source = #table({"薬品名", "包装単位", "列数"}, {})
in
    Source


// ================================================================================
// E クエリ名：追加休業日
// ================================================================================
let
    Source = #table({"日付", "理由"}, {})
in
    Source


// ================================================================================
// F クエリ名：薬品グループ
//    成分規格：成分と規格（例：タンドスピロン 10mg）
//    需要のまとまり：入れ替えて使える薬の組。先発に固定の需要は先発だけの組にする
//    先発後発：先発／後発 など
// ================================================================================
let
    Source = #table({"薬品名", "成分規格", "需要のまとまり", "先発後発"}, {})
in
    Source
